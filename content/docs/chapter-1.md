# Chapter 1: Getting Started

This is your first official documentation or book page. The Hugo Book theme reads files inside the `content/docs/` directory and turns them into menu items on the left side of your screen.

## How the Sidebar Works

The sidebar order is controlled by the `weight` parameter in the front matter (the configuration block at the top of this file):

* `weight: 1` appears first.
* `weight: 2` will appear second, and so on.

### Sub-sections
If you want to create a sub-menu, you can create a folder inside `docs` (like `content/docs/nested-topic/`) and place an `_index.md` file inside it.
